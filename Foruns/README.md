# 📖 Foruns — Novo Livro: *O Foragido*

Esta pasta arquiva os pareceres de leitura crítica do manuscrito de
*O Foragido*, trocados entre Miguel do Rosário e as IAs da "Trindade"
(Kimi/ZCode, Antigravity/Google e Claude/Anthropic).

> Nota: este repositório (`moka`) hospeda o app de leitura. A pasta
> `Foruns/` foi criada aqui porque o `moka` é um dos dois repositórios da
> ponte de escrita Claude ↔ GitHub (25/07/2026). O manuscrito em si
> (frontmatter, capítulos, `MANUAL_DE_ESTILO.md`, `REFERENCIA_LITERARIA.md`)
> ainda **não** está versionado em nenhum dos dois repositórios — ver
> pedido em `resposta_claude_leitura_livro.md`.
